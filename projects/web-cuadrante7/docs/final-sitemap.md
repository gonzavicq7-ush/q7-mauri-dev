# final-sitemap.md

## Estructura recomendada v1

La versión inicial recomendada para `cuadrante7.com` es un **sitio corto multipágina**, no una single-page estricta.

Esto permite:
- salir rápido
- mantener foco
- mejorar SEO básico
- crecer sin rehacer la arquitectura

## Páginas principales

### 1. Inicio (`/`)
Objetivo:
- presentar posicionamiento
- mostrar líneas de servicio
- explicar enfoque de trabajo
- generar confianza
- llevar a contacto

Bloques sugeridos:
- Hero
- Líneas de servicio
- Qué resolvemos
- Cómo trabajamos
- Señales de confianza
- CTA final

### 2. Servicios (`/servicios`)
Objetivo:
- consolidar las capacidades principales
- ordenar la oferta en 3 líneas claras

Subbloques sugeridos:
- Oracle APEX y soluciones empresariales
- Infraestructura y operación tecnológica
- Automatización e integración

### 3. Nosotros (`/nosotros`)
Objetivo:
- explicar el enfoque de Cuadrante7
- transmitir experiencia sin convertir la página en un CV largo

Bloques sugeridos:
- Quiénes somos
- Qué enfoque tenemos
- Cómo trabajamos
- Por qué esta combinación de capacidades importa

### 4. Contacto (`/contacto`)
Objetivo:
- facilitar una primera conversación técnica o diagnóstico inicial

Bloques sugeridos:
- invitación breve
- formulario
- selector de necesidad
- CTA

## Extensiones futuras recomendadas

### 5. Soluciones (`/soluciones`)
Para más adelante, si hace falta:
- modernización de sistemas
- integración y automatización
- portales y aplicaciones internas
- continuidad operativa

### 6. Casos o experiencias (`/casos`)
Solo cuando haya material suficiente para mostrarlo con criterio.

## Decisión editorial clave

La web v1 debe apoyarse en 3 líneas de servicio principales:
1. Oracle APEX y soluciones empresariales
2. Infraestructura y operación tecnológica
3. Automatización e integración

La IA aplicada debe presentarse como capacidad transversal dentro de automatización e integración, no como línea independiente en la versión inicial.
