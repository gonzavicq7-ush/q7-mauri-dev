# design-direction.md

## Dirección visual recomendada

La web de Cuadrante7 debe sentirse:
- sobria
- técnica
- limpia
- profesional
- contemporánea

## Qué evitar

- estética startup colorida
- visuales exagerados
- diseño recargado
- exceso de animaciones
- iconografía infantil o demasiado informal

## Paleta sugerida

- base oscura o neutra
- acentos fríos (azules, cyan, slate)
- contraste suficiente para lectura cómoda

## Tipografía

- sans-serif moderna y limpia para títulos y texto general
- evitar combinaciones excesivas
- si se usa monospace, que sea solo para detalles muy puntuales

## Sensación buscada

Debe transmitir:
- criterio técnico
- seniority
- claridad
- confianza operativa

## Componentes visuales clave

- cards sobrias para líneas de servicio
- timeline o pasos simples para “cómo trabajamos”
- bloques de contenido con bastante aire
- CTAs claros pero no agresivos

## Regla general

El diseño debe acompañar el posicionamiento: una consultora técnica seria que implementa y opera, no una agencia visual ni una startup de moda.
