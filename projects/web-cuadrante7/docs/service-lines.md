# service-lines.md

## Líneas de servicio propuestas

### 1. Oracle APEX y soluciones empresariales

En esta línea entran:
- desarrollo de aplicaciones de negocio
- modernización de sistemas internos
- portales internos y externos
- gestión documental y procesos
- plataformas SaaS sobre Oracle APEX
- integración con bases de datos y servicios existentes

### 2. Infraestructura y operación tecnológica

En esta línea entran:
- virtualización
- servidores y storage
- networking
- continuidad operativa
- arquitectura base para aplicaciones y servicios
- ordenamiento y mejora de entornos operativos

### 3. Automatización e integración

En esta línea entran:
- automatización de procesos con n8n
- integración entre sistemas
- orquestación de flujos operativos
- asistencia e inteligencia aplicada a procesos concretos
- mejora de productividad y reducción de tareas manuales

## Regla de presentación

Las líneas deben mostrarse como capacidades complementarias, no como servicios aislados. El valor de Cuadrante7 está en combinar desarrollo, infraestructura y automatización dentro de una solución coherente.
