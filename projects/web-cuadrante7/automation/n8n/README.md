# n8n

Este directorio queda reservado para documentación, ejemplos o definiciones de flujos de automatización vinculados a la web.

## Uso esperado

- automatización de leads
- clasificación de consultas
- notificaciones internas
- integraciones futuras

## Regla

Toda integración con n8n debe diseñarse con criterio de seguridad y no exponer directamente automatizaciones internas sin control.
