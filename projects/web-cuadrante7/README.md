# web-cuadrante7

Proyecto base para la nueva web corporativa de Cuadrante7.

## Objetivo

Implementar una web rápida, segura y mantenible para presentar servicios de:
- desarrollo e implementación de soluciones en Oracle APEX
- infraestructura de centros de datos
- automatización con n8n e inteligencia artificial

## Estado actual

- estructura inicial creada
- Git local inicializado
- documentación base preparada
- arquitectura propuesta orientada a salida rápida y segura
