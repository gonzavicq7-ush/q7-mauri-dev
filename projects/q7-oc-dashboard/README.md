# q7-audio2md

Herramienta para transcribir audios largos y exportarlos a texto plano o Markdown.

## Objetivo
- Procesar audios grandes sin cargar todo el contenido en memoria.
- Soportar formatos comunes de grabadoras y iPhone.
- Exportar a `.txt` y `.md`.
- Manejar archivos grandes por segmentos para evitar límites de tamaño.
